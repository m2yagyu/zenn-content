## 確かめられたこと

この本で見てきたのは、結局のところ1つのことです。**生成AIの中で起きていることの多くは、物理がすでに持っていた言葉で書ける。**

| AI側の言葉 | 物理側の言葉 |
|---|---|
| softmax | ボルツマン分布 |
| ロジット | エネルギー（の符号反転） |
| softmaxの分母 | 分配関数 $Z$ |
| `temperature` | 温度 $\mathcal{T}$ |
| perplexity | $e^S$（実効的な状態数） |
| Attentionの重み | Hopfield模型の想起 |
| $1/\sqrt{d}$ | 次元によらず温度を一定に保つ係数 |
| attention sink | 行き場のない重みの捨て場所 |
| forward process | 拡散方程式 |
| reverse process | ランジュバン方程式を時間反転したもの |
| スコア関数 $\nabla_x \log p_t(x)$ | ポテンシャルの勾配（＝力） |
| ノイズスケジュール $\beta_t$ | 温度のスケジュール |

これは偶然の一致ではありません。Hopfieldが2024年にノーベル**物理学**賞を受けたのは、この対応が本物だからです。

## この対応が実務で効く場面

言い換えができると、デバッグの勘が効くようになります。

- **出力が単調になる／崩壊する** → 実効温度の問題として見る。$\mathcal{T} \to 0$ でエントロピーが0に潰れる挙動は3章で測ったとおりです
- **長い文脈で性能が落ちる** → Attentionの重みが薄く広がる、つまり温度が上がりすぎている状態として見る。4章の「有効注目数」がそのまま指標になります
- **拡散モデルの生成が破綻する** → 平衡に達する前に打ち切っている可能性を疑う。6章で見た $\bar\alpha_{T-1}$ が十分に0まで落ちているかの確認です

## まだ書いていないこと

この本には、意図的に入れていない話があります。

**フローマッチング（rectified flow）。** 6章と7章で扱ったのはDDPMの系譜ですが、いま実際に使われているStable Diffusion 3やFLUXは、フローマッチングという別の定式化に移っています。物理の言葉で言えば、確率微分方程式（SDE）から常微分方程式（ODE）へ、ランダムな揺らぎを含む記述から確率流だけの記述へ、という移行です。そしてこのとき、6章でノイズスケジュールとして出てきた $\beta_t$ が消えます。**温度を捨てた拡散モデル**が、いまの画像生成の主流です。

**位置の埋め込み。** 4章ではAttentionが「何を」思い出すかを見ましたが、「どこにあったか」をどう表現するかには触れていません。RoPEが回転群を使って相対位置を表す仕組みは、それ自体で1章分あります。

**学習側の物理。** この本は一貫して推論時の話をしています。損失地形、SGDの揺らぎ、汎化と温度の関係といった学習側の話は、統計力学の応用としてはむしろ本丸ですが、扱っていません。
