# note の実測解析（2026-08-11 実施）

`note.com/api/v3` から **3,214件**（公開7日以上経過）を、本文・タグ・著者フォロワー数まで収集して解析した記録。
宛先は**プログラミング未経験の完全初心者**。noteの投稿方針の根拠はここに置く。再測は同じ手順で行う。

収集: `hashtags/{tag}/notes` で候補を集め、`notes/{key}` で本文とタグ、`v2/creators/{name}` でフォロワー数。
対象タグ: 統計学 / 物理学 / 数学 / 大人の学び直し / リスキリング / 独学 / プログラミング初心者 /
プログラミング / 機械学習 / データ分析 / 資格勉強 / 学び直し / 科学 / サイエンス / AI活用 /
ChatGPT / 生成AI / AI初心者 / エンジニア / キャリア

## 0. 方法（ここを外すと全部無意味になる）

**フォロワー数が支配的なので、層別しないと「勝者にはフォロワーがいる」を再発見するだけになる。**

| 著者のフォロワー層 | n | スキ中央値 | 上位25% | スキ0率 |
|---|---|---|---|---|
| 0-49 | 1,505 | 1 | 3 | 32% |
| 50-199 | 538 | 2 | 7 | 13% |
| 200-999 | 748 | 6 | 12 | 7% |
| 1000+ | 421 | 19 | 34 | 5% |

そこで**各層の中で** WIN=上位25% / BASE=下位50% と定義した。
結果: WIN 805件 / BASE 1,605件。
**WINのフォロワー中央値65 / BASEの中央値66** ——ほぼ一致しており、層別は成功している。
この状態でWIN中央値12スキ / BASE中央値1スキ。この差は**書き方の差**である。

以下の「WIN率」は WIN/(WIN+BASE) で、母集団平均は **33.4%**。
33.4%より高ければ有利、低ければ不利と読む。

### Zennとは真逆になる型がある（重要）

**Zennのルールをnoteに持ち込んではいけない。** 同じ型が逆に出る。

| 型 | ZennのWIN率 | noteのWIN率 |
|---|---|---|
| 〜してみた | 20.7%（最悪） | **66.7%（最良）** |
| 疑問形 | 65.6%（有利） | **23.6%（不利）** |
| 具体的な製品名 | 75.7%（最強） | — |

Zennは「何が分かるか」を問われる場所、noteは「誰が何をやったか」を読まれる場所。
noteで疑問形が沈むのは、**問いを立てる記事より、やった記録が読まれる**ため。

### 「【】+ 数字 + 年号」は最も不利な組み合わせ

【2026年最新】〜5選、のような型は、BASE側に集中している（年号のWIN率11.7%）。
SEO記事の型であり、noteの読者はこれを飛ばしている。

### 画像が単独で最大の要因

| 画像の枚数 | WIN | BASE | WIN率 |
|---|---|---|---|
| 0枚 | 456 | 1,185 | **27.8%** |
| 1-2枚 | 144 | 220 | 39.6% |
| **3-5枚** | 120 | 116 | **50.8%** |
| 6枚〜 | 85 | 84 | 50.3% |

**0枚から3-5枚で、WIN率が27.8%→50.8%へほぼ倍増する。**
しかも中央値が0枚ということは、**大半が使っていない**。最も空いているレバー。
6枚以上に増やしても伸びないので、**3〜5枚が最適**。

### 文字数は1,500〜3,000字

| 文字数 | WIN率 |
|---|---|
| 〜800字 | **20.6%** |
| 800-1,500 | 35.9% |
| **1,500-3,000** | **37.8%** |
| 3,000-6,000 | 35.5% |
| 6,000字〜 | 33.2% |

Zennの「8,000字以上」とは全く違う。**noteで長文は効かない。**
800字未満だけは明確に不利なので、そこは超える。

### 段落は短く、多く

WINは段落数61・1段落28字。BASEは49段落・31字。
**改行を多く、1段落を短く。** スマホで読まれることを前提にした書き方。

### 理系タグは全滅（前回の暫定所見を撤回）

`物理学` 22% / `統計学` 26% / `数学` 20% / `機械学習` 20%。すべて母集団平均33.4%を下回る。

前回、回転の遅さ（統計学は1日16本）と天井（最大95スキ）を根拠に
`統計学` を主軸に推したが、**層内で見ると不利**だった。
あの天井はフォロワーを持つ著者が作ったもので、書き方の優位ではなかった。

**解釈**: 理系タグは「解説」を呼び込み、解説は読まれない。
学び系タグは「体験」を呼び込み、体験は読まれる。
第5節の書き出しの型がこれを裏づけている。

**使うタグ**: `大人の学び直し` `リスキリング` `学び直し` `プログラミング初心者` `プログラミング` `AI`。
理系タグは付けてもよいが主軸にしない。

## 5. 書き出し（フォロワー200人未満のWINの実物）

- 「私、キーボードを打つとき、手元を見ながらポツポツ押すくらいのレベルなんです」（73スキ / F183）
- 「こんにちは、りなです。前回は初投稿だったのですが、たくさんのスキをありがとうございました」（64スキ / F183）
- 「最近、AIを使わない日はほとんどありません」（40スキ / F183）
- 「お久しぶりです。サラリーマンコウジ…… 改め、絶賛"無職"のコウジです」（118スキ / F33）
- 「前回から2週間もあったのに、ライブが2回も挟まって、ろくに練習できてませんでした」（42スキ / F150）

### 共通する型

1. **自分の状態から入る**。自分の弱さ・できなさから始まるものが多い
2. **名乗る**。「こんにちは、〇〇です」
3. **読者との関係を前提にする**。「前回は」「ありがとうございました」
4. **「この記事では〜を解説します」型が一つも無い**

Zennの「この記事を読むと〜ができるようになります」は、noteでは使わない。

## 7. 前回の暫定所見からの訂正

2つ撤回する。どちらも層別前の粗い集計にもとづくものだった。

1. **「統計学タグを主軸に」→ 撤回。** 層内WIN率26%で不利。学び系タグを使う
2. **「連載番号を出す」→ 撤回。** タイトルの連載番号はWIN率24.4%で不利。
   連載にすること自体は否定されないが、**通し番号をタイトルに出すと新規読者が入れない**。
   各回のタイトルは単体で成立させる
